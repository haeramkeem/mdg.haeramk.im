## 최종

- [[TO_DATE Function (SQL)|TO_DATE()]] 으로 풀면 된다.

```sql
SELECT mcdp_cd AS "진료과 코드", COUNT(apnt_ymd) AS "5월예약건수"
FROM appointment
WHERE apnt_ymd >= TO_DATE('2022-05-01', 'YYYY-MM-DD')
AND apnt_ymd < TO_DATE('2022-06-01', 'YYYY-MM-DD')
GROUP BY mcdp_cd
ORDER BY COUNT(apnt_ymd) ASC, mcdp_cd ASC;
```
