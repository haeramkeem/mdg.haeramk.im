- 쉬운 문제

```sql
SELECT DISTINCT c.car_id
FROM car_rental_company_car c, car_rental_company_rental_history h
WHERE c.car_id = h.car_id
AND car_type = '세단'
AND h.start_date >= STR_TO_DATE('20221001', '%Y%m%d')
ORDER BY c.car_id DESC;
```
