- Inner query 로 하면 된다.

```sql
SELECT h.flavor
FROM first_half h,
(SELECT flavor, SUM(total_order) AS sum_order FROM july GROUP BY flavor) j
WHERE h.flavor = j.flavor
ORDER BY h.total_order + j.sum_order DESC
LIMIT 3;
```
